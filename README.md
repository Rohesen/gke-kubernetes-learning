# ☸️ GKE & Kubernetes Hands-On Labs

> A hands-on learning repository documenting my journey with **Kubernetes, Google Kubernetes Engine (GKE), Deployments, Monitoring, Prometheus, Docker, Artifact Registry, and Kubernetes troubleshooting**.

---

## 📌 About This Repository

This repository contains my practical work from Google Cloud Skills Boost labs focused on managing Kubernetes workloads on **Google Kubernetes Engine (GKE)**.

Instead of only completing the labs, I am documenting:

- 🧠 Kubernetes concepts
- ⚙️ Commands used
- 📝 YAML manifests
- 🐳 Containerization
- 📊 Monitoring with Managed Prometheus
- 🔍 Troubleshooting
- 🚀 Deployment strategies
- ☁️ GKE infrastructure
- 💡 Key learnings and real-world use cases

The goal is to build a strong practical foundation for **DevOps / Cloud / Data Engineering** roles.
